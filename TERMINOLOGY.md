# Terminology and units

The canonical model stores a coded concept as code, code system, optional version, display, and source. Units are code plus unit system and optional display. This is a reference model, not a terminology server: no LOINC, SNOMED CT, ICD, UCUM, or DICOM terminology content, mapping, conversion, validation, or licensing claim is implemented. Any future normalization must retain source and normalized value/unit with transformation provenance.
